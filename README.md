### 🌐 AI Browsing Agent
Agentic **RAG** system that crawls any URL with headless Chromium/Playwright, embeds content with `all-MiniLM-L6-v2` into a **FAISS** vector store, and answers natural-language questions through **LLaMA 3.3 70B** (Groq) behind a **FastAPI** backend and **Gradio** frontend.

- 🔁 Multi-iteration agent loop with **cosine-similarity link ranking** to autonomously crawl relevant subpages when retrieval confidence is low
- 🧩 Manual JSON-based tool calling to work around Groq's server-side parsing limitations
- ♻️ Chunk deduplication across iterations to prevent context repetition
